# Обзор проекта

Этот проект представляет собой full-stack приложение, состоящее из beckend API и frontend одностраничного приложения (SPA). Включает такие функции, как аутентификация пользователей, запросы и мутации GraphQL, современный интерфейс, а также развертывание с использованием Nginx в качестве обратного прокси.

## Структура проекта

- **GraphQL API:** Запросы и мутации GraphQL для взаимодействия с данными.
- **Модуль магазина:** Логика работы с данными магазина.

### Фронтенд

Фронтенд представляет собой SPA на React, которое взаимодействует с бэкенд API через GraphQL. Он включает страницы для регистрации пользователей, входа, отзывов и личного кабинета.

#### Основные особенности:
- **Аутентификация пользователей:** Страницы для входа и регистрации.
- **Интеграция с GraphQL:** Поддержка отправки и получения данных через GraphQL.
- **UI-компоненты:** Повторно используемые UI компоненты, такие как формы, модальные окна и карточки.
- **Маршрутизация:** Страницы для разных разделов приложения, включая отзывы, главную страницу и личный кабинет.
